真实存在的限制，写在明面上：TAR 与 WIM 不支持加密（7-Zip 会静默忽略密码，所以界面上直接置灰）；GZIP / BZIP2 / XZ 是单流格式，压目录先打一层 tar，解压时自动拆掉；不创建 RAR——7-Zip 不支持，许可也不允许；ZSTD / LZ4 / Brotli 需要非官方分支，不做假选项。

Safety

小心对待每一个包。

压缩包是别人递到桌面的东西。千梭在解压前后都设了检查，文件只写到该写的地方。

01

解压前先预检

每次解压前把全部条目过一遍：绝对路径、~、盘符、UNC 一律拦下。可疑的包在窗口里明说，去不去由你决定。

02

同名永不覆盖

解压时 a.txt 自动改名 a_1.txt；压缩产物重名就换序号。你的原始文件永远是原始文件。

03

解压后再复核

落盘之后复查有没有越界文件。../ 这类会被引擎剥平的路径，也会在结果通知里说一声，不静默糊弄。

把压缩这件事，交给右键。

下载 DMG，拖进「应用程序」，启用一次访达扩展，从此压缩只是右键的事。

FAQ

常见问题。

双击打不开，提示无法验证开发者？
千梭没有做 Apple 公证，第一次打开会被 Gatekeeper 拦下。在「应用程序」里右键点千梭 → 选「打开」→ 再点「打开」，之后即可正常双击启动。
右键菜单里没有「用千梭压缩」？
访达扩展需要手动启用一次：打开 系统设置 → 通用 → 登录项与扩展 → 访达，勾选「千梭」即可。启用后，选中归档显示「用千梭解压 / 解压到…」，选中其他文件显示「用千梭压缩 / 压缩为…」。
能处理 RAR 吗？
能开、能看、能解，包括带密码的 RAR 和分卷。但创建 RAR 做不到——7-Zip 本身不支持，许可也不允许。要打包就用 ZIP 或 7Z，压缩率同样能打。
支持加密吗？
ZIP 用 AES-256，7Z 用 7zAES。TAR 和 WIM 不支持加密——引擎会静默忽略密码参数，所以界面里这两种格式的密码选项直接置灰，不做假选项。
为什么没有 ZSTD、LZ4、Brotli？
官方 7zz 引擎不支持这些算法（需要第三方 ZS 分支，返回码是 2）。千梭坚持用官方引擎，宁可没有，不做假选项。
需要什么系统配置？
macOS 14.0 及以上，Apple 芯片与 Intel 芯片通用的 Universal 2 构建，7-Zip 引擎已内置，不依赖系统里装没装别的工具。
文件和数据会上传吗？
所有压缩、解压、浏览都在你自己的 Mac 上由内置引擎完成，不上传任何文件内容、密码或路径。App 本身从 GitHub Releases 直接下载。
